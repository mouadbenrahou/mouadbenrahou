## 🍳 ChefSphere

A meal-planning app for couples: you each swipe recipes, matches become meals, and the week plan and grocery list are generated automatically. Live on iOS, Android and web, in 5 languages, with paid plans. Accepted into the Anthropic startup program in October 2026.

- **Flutter** app for iOS & Android, **Next.js** web app (public site, accounts, marketplace)
- **NestJS** APIs: auth, payments, background jobs, real-time
- **AI layer:** per-task LLM routing across providers (chat, planning, recipe extraction, fridge-photo vision) and RAG over recipes, ranked for each user's diet, allergies, time, budget and likes
- **Creator side:** ebook and kitchen-tool marketplaces, live cooking streams, Stripe payments and Stripe Identity
- Runs on self-managed **Kubernetes** with **Cloudflare R2**
